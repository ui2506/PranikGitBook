# Кастомные SCP предметы

## SCP-1162

SCP-1162 находится в комнате SCP-173.

Объект позволяет обменять находящийся у игрока предмет на другой случайный предмет.

### Использование

Для использования SCP-1162 необходимо взаимодействовать с объектом, держа предмет.

Предмет из руки будет поглощён SCP-1162.

После этого игрок может получить случайный предмет.

### Возможные результаты

Среди обычных предметов:

* адреналин;
* монета;
* фонарик;
* светошумовая граната;
* ключ-карта уборщика;
* пропуск на поверхность;
* рация.

Более редкие результаты могут включать:

* аптечку;
* карту инженера содержания;
* COM-15;
* ключ-карту O5;
* карту менеджера комплекса;
* карту капитана МОГ;
* SCP-268;
* SCP-1344.

### Потеря предмета

Существует примерно **5% шанс**, что SCP-1162 заберёт предмет и ничего не вернёт.

### Возвращение потерянных вещей

SCP-1162 запоминает некоторые предметы, которые игрок ранее выбрасывал.

В определённых случаях вместо нового предмета объект способен вернуть один из таких предметов.

### Пустые руки

Использование SCP-1162 без предмета опасно.

Игрок получает **60 единиц урона**.

Если здоровья недостаточно, взаимодействие может привести к смерти.

## SCP-294

SCP-294 — торговый автомат с необычными напитками, расположенный в большой офисной комнате Entrance Zone.

Для покупки используется монета.

### Как использовать

1. Возьмите монету в руку.
2. Взаимодействуйте с SCP-294.
3. Выберите напиток командой `.scp294 <название>`.
4. Повторно взаимодействуйте с автоматом.
5. Дождитесь приготовления напитка.

{% hint style="warning" %}
SCP и некоторые специальные роли использовать SCP-294 не могут.

Необходимо отключить Do Not Track.
{% endhint %}

### Время приготовления

Обычные напитки готовятся быстрее специальных.

Во время приготовления не рекомендуется уходить далеко от SCP-294.

Если инвентарь заполнен или игрок отошёл слишком далеко, приготовленный стакан может появиться возле автомата.

***

## SCP-1499

SCP-1499 представлен в виде противогаза.

В начале раунда объект появляется возле комнаты SCP-096.

### Использование

При использовании SCP-1499 игрок временно покидает обычный комплекс и перемещается в отдельное пространство.

Примерно через **10 секунд** игрок возвращается в то место, из которого использовал SCP-1499.

### Ограничения

Находясь под действием SCP-1499, игрок не может использовать его как способ обычного побега из комплекса.

После взрыва боеголовки возврат в небезопасную точку может привести к смерти.
