# Обычные SCP

В первые 30 секунд после начала раунда SCP не могут взаимодействовать с дверями. Это время также используется для возможности поменять свою роль на другого SCP с помощью [SWAP](../../group-1/vybor-roli-v-nachale-raunda.md#scp).
