# Обычные SCP

В первые 30 секунд после начала раунда SCP не могут взаимодействовать с дверями. Это время также используется для возможности поменять свою роль на другого SCP с помощью [SWAP](../../vybor-roli-v-nachale-raunda.md#scp).

## SCP Proxy Chat

Некоторые SCP могут разговаривать с людьми через локальный голосовой канал.

По умолчанию переключение Proxy Chat выполняется клавишей: **V**

Поддерживаемые SCP:

* SCP-049;
* SCP-049-2;
* SCP-096;
* SCP-106;
* SCP-173;
* SCP-3114;
* SCP-939.

При включении голос SCP слышен людям в непосредственной близости.

Максимальная дистанция составляет примерно **12 метров**.
