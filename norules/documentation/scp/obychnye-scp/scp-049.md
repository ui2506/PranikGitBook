# SCP-049

### Изменения

#### Смертельное прикосновение

Обычная атака SCP-049 мгновенно убивает жертву.

#### Ускоренное воскрешение

Для превращения трупа в SCP-049-2 требуется около **5 секунд**.

#### Взаимодействие с воротами

При наличии активной цели способности Sense SCP-049 способен взаимодействовать с некоторыми воротами, которые в стандартной игре недоступны ему обычным способом.
