# Кастомные SCP

Каждый кастомный SCP имеет собственные способности, характеристики и условия появления.

***

## Как выбрать кастомного SCP

Перед началом каждого раунда сервер формирует список доступных кастомных ролей.

Кастомные роли разделены на несколько типов, включая агрессивные и дружественные. Из каждого типа сервер случайно выбирает доступную роль на текущий раунд.

Игрок может заранее подать заявку на выбранную кастомную роль.

Команда: `.cscp` или `.customscp`

* Команда показывает кастомные роли, доступные в текущем раунде.

Чтобы записаться на роль: `.cscp <ID>`

{% hint style="info" %}
У каждой роли есть минимальное необходимое количество игроков.

Если на одну роль записались несколько игроков, владелец роли выбирается случайно перед началом раунда.

Некоторые SCP появляются как предмет на карте, и вручную через систему выбора не выдаётся.
{% endhint %}

{% hint style="warning" %}
Запись на кастомную роль не гарантирует её получение
{% endhint %}
