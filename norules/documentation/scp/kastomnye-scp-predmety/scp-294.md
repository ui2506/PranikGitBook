# SCP-294

SCP-294 — торговый автомат с необычными напитками, расположенный в большой офисной комнате Entrance Zone.

Для покупки используется монета.

### Как использовать

1. Возьмите монету в руку.
2. Взаимодействуйте с SCP-294.
3. Выберите напиток командой `.scp294 <название>`.
4. Повторно взаимодействуйте с автоматом.
5. Дождитесь приготовления напитка.

{% hint style="warning" %}
SCP и некоторые специальные роли использовать SCP-294 не могут.

Необходимо отключить Do Not Track.
{% endhint %}

### Время приготовления

Обычные напитки готовятся быстрее специальных.

Во время приготовления не рекомендуется уходить далеко от SCP-294.

Если инвентарь заполнен или игрок отошёл слишком далеко, приготовленный стакан может появиться возле автомата.
