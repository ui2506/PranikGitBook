# Система отрядов

В начале раунда обе стороны имеют равные позиции:

**МОГ — 50**\
**Повстанцы Хаоса — 50**

Действия игроков изменяют преимущество своей стороны.

### Получение очков

| Действие                                                            | Изменение |
| ------------------------------------------------------------------- | --------- |
| Первый подбор нового предмета представителем своей фракции          | +1        |
| Убийство противника                                                 | +1        |
| Убийство SCP                                                        | +5        |
| Успешный побег                                                      | +10       |
| После появления отряда противоположная сторона получает компенсацию | +35       |

Перед следующей волной сравниваются очки МОГ и Повстанцев Хаоса.

Сторона с большим количеством очков получает право на появление.

При равном результате сторона выбирается случайно.

Наблюдатели получают дополнительную информацию о времени до следующего отряда.
