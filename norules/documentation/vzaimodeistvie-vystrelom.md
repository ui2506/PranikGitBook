# Взаимодействие выстрелом

Некоторые элементы комплекса можно активировать выстрелом.

### Двери

Выстрел по обычной незапертой двери без требований доступа может открыть или закрыть её.

Защищённую ключ-картой дверь таким способом открыть нельзя.

### Лифты

Выстрел по панели работающего лифта может вызвать его или отправить на другой этаж.

### Камеры SCP-079

Попадание по используемой SCP-079 камере временно нарушает сигнал SCP-079.
